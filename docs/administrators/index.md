# The documentation for administrators

These pages are for whoever administers the tenants of an instance and the people in them, through the
administration API and its terminal client. Installing and running the instance is in
[the documentation for operators](../operators/index.md), writing an application that signs people in
through it is in [the documentation for developers](../developers/index.md), and what a person does with
their account is in [the documentation for users](../users/index.md).

| Section | What it holds |
|---|---|
| [The terminal client](terminal-client.md) | Installing the client of the administration API, connecting it to an instance, and what it does |
| [People](people/users.md) | A person of a tenant, their credentials, their sessions, their groups and the identities linked to them |
| [SCIM](scim/index.md) | Provisioning from a directory, which is not implemented |
