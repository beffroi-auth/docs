# Console commands

The bundle adds the commands for the tenant, users and their journal, groups, clients, keys, data keys, SAML
metadata, the databases of addresses and FIDO metadata. They are listed, grouped and described in [the
reference](../reference/console-commands.md).

This page will describe the ones that need explaining beyond their help: the rotation of a key, the
rewrapping of data keys, and the destruction that cannot be undone.
