# The documentation for operators

These pages are for whoever installs Beffroi, sets it through its environment and keeps the instance
running. Administering the people of a tenant is in [the documentation for administrators](../administrators/index.md),
writing an application that signs people in through it is in [the documentation for developers](../developers/index.md),
and what a person does with their account is in [the documentation for users](../users/index.md).

| Section | What it holds |
|---|---|
| [Getting started](getting-started/installation.md) | What the application needs, running it on your machine and as a deployment, then the tenant and its keys |
| [The application](application/index.md) | The image, its variables, the planes, persistence, security, key management, the pages, messaging, the console, operating and observing it |
| [The tenant](tenant/tenants.md) | The tenant as the environment declares it, its keys, and the personal data it seals |
| [SAML 2.0](saml/index.md) | The tenant as the identity provider of SAML applications and as the service provider of upstream identity providers |
| [Reference](reference/configuration.md) | Every option of the configuration tree, and every console command |
